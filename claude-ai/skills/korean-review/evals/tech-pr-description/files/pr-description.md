# 캐시 무효화 개선

## 배경

기존 구현은 만료 시간을 가지고 있지 않아서, 원본 데이터가 바뀌어도 오래된 값이 계속 반환되었습니다. 요청은 요청 → cache 조회 → 미스 시 DB 조회 순서로 처리됩니다.

## 변경 사항

캐시 키에 대한 정규화 처리가 추가되어졌습니다. 만료된 항목은 다음 조회 때 재캐시화합니다. TTL은 설정 파일에 의해 결정됩니다. 읽기 경로는 바뀌지 않았습니다; 쓰기 경로만 바뀌었습니다.

`normalizeKey()` 함수는 호출자가 키를 이미 정규화했는지 안다. 그래서 두 번 정규화하지 않습니다.

## 기대 효과

이 변경은 캐시 계층에 숨을 불어넣습니다. 캐시 적중률이 오르고 DB 부하가 줄어듭니다.
