# 0123 — 겹친 ADR 번호 0087과 0092는 바꾸지 않고, 각 파일에 겹친 상대를 적는다

2026-10-15에 ADR 번호 두 개가 겹쳤다. 0087은 [[0087-repin-items-to-2026-10-15]]와 [[0087-evals-measure-settings-per-model]]이고, 0092는 [[0092-verify-repo-facts-for-decisions]]와 [[0092-drop-review-target-eval-case]]다. 번호는 바꾸지 않았다. 대신 네 파일 끝에 겹친 상대 파일을 적고, 다른 문서의 "ADR 0087"과 "ADR 0092"가 어느 쪽을 가리키는지 적었다.

## 고려한 것

- **나중에 만든 쪽의 번호를 바꾼다.** 하지 않는다. commit 메시지의 "(ADR 0087)"과 "(ADR 0092)"는 고칠 수 없어서, 번호를 옮기면 메시지와 파일이 어긋난다.
- **다른 문서의 참조를 모두 파일 이름으로 바꾼다.** 하지 않는다. 8개 파일의 10곳을 고쳐야 한다. 그런데 두 번호 모두 eval을 다루는 ADR과 그렇지 않은 ADR로 나뉘어서, 문맥만으로도 어느 쪽인지 갈린다.
- **`bin/check-integrity`에 번호 중복 검사를 더한다.** 이번에는 하지 않는다. 0093부터 0122까지 30개 ADR에서는 번호가 다시 겹치지 않았다. 다시 겹치면 그때 더한다.
