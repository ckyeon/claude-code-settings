# 0121 — 한국어 규칙 파일을 그 파일의 규칙으로 점검해 자기 위반 여덟 건을 고친다

사용자 요청으로 `korean-technical-writing.md`를 그 파일 자신의 규칙에 한 줄씩 대어 봤다. 분명한 위반 다섯 건과 판단이 필요한 위반 여섯 건이 나왔고, 사용자가 앞의 다섯 건과 34행의 세 건을 받았다. 규칙의 뜻과 문서 구조는 바꾸지 않았다.

## 고친 것

| 행 | 걸린 규칙 | 바꾼 내용 |
|---|---|---|
| 3, 54 | 원칙 3 | "절"이 문서의 section과 문법의 clause(42행) 두 뜻으로 쓰였다. clause 쪽은 [[0048-loosen-sentence-joining-rule]]이 고른 문구라 두고, section 쪽 두 곳을 "절" 없이 풀었다 |
| 9 | 원칙 3 | 원칙 3이 같은 대상을 "용어"와 "단어"로 불렀다. "단어"를 "용어"로 바꿨다 |
| 3 | 원칙 1 | 7행이 원어로 쓸 용어의 예로 드는 commit을 "커밋"으로 썼다. "commit"으로 바꿨다. user scope의 다른 한국어 파일도 commit을 원어로 쓴다 |
| 54 | 꾸민 산문 | 꾸민 산문을 정의하는 문단에 "은유가 끌고 오는 함의"라는 은유가 있었다 |
| 24 | 은유 압축 | "한국어를 눌러 쓸 때"를 무엇을 줄이는지 밝힌 문장으로 바꿨다 |
| 34 | 원칙 2(b), 원칙 3 | "전례"가 24행에서는 앞선 사례를, 34행 괄호에서는 고른 이유를 뜻했다. 34행에서 "전례"를 빼고 "고른 이유"만 남겼다 |
| 34 | 원칙 3 | 같은 대상을 "용어집"과 "glossary 파일"로 불렀다. "용어집 파일"로 맞췄다 |
| 34 | 과압축 | 맥락 없이는 읽히지 않는 예시 "장치는 패턴으로"를 뺐다. 남은 예시가 용어가 아니라 표기 선택이므로 주어를 "도메인 용어를 어떻게 쓸지"로 바꿨다 |

## 받지 않은 것

- **근거가 약한 세 건.** 7행 "번역어가 두 의미를 떠안거나", 10행 "연결 산문", 50행 "기호로 쓰인 파일"이다. 50행은 [[0102-unpack-korean-rule-sentences]]가 범위가 좁아진다는 이유로 지킨 문구다.
- **"확립 용어"를 "확립된 용어"로 푸는 안.** 점검에서는 명사 나열 조어로 봤지만, 사용자의 다른 프로젝트 문서 여럿이 이미 "확립 용어"를 용어로 쓰고 있어 그대로 두었다.

## Consequences

- 사전으로 확인하지 못했다. 표준국어대사전 검색 페이지는 robots.txt가 자동 조회를 막는다. 24행 "눌러 쓰다"와 34행 "전례"의 뜻 판단은 모델 지식에 기댔다.
- 이 파일의 사본을 두고 원본과 같은지 검사하는 프로젝트는 사본을 다시 복사해야 한다.
- 파일은 2542자에서 2545자로 거의 그대로다.
