# 0027 — git repo 없는 디렉터리 반출 포기, gigr 인수인계 완료 기록

[runbook](../migration-2026-08-31.md) §3의 비-git 디렉터리 4곳(cs231n_2017·hackers·learn·datagrip-projects, 총 ~4.9G)을 반출 목록에서 뺀다 — 진행 중인 작업이 아닌 자료 보관이고 재다운로드·재구성 가능하다는 사용자 판단. ADR 0026이 좁힌 "작업 연속성" 목적과도 정합한다. 부수 효과로 `datagrip-projects` 내부의 개인/회사 분류 문제가 소멸한다. gigr 저장소 인수인계는 완료로 확인되어 runbook의 미결 항목에서 닫는다.
