# 0153 — 2026-11-26 korean-review가 빠진 정보도 묻게 한 수정을 받고, eval로 효과를 확인

[[0152-ai-slop-guide-case-fixes-and-baseline]]은 skill을 쓰면 문서에 빠진 정보를 덜 묻는다고 기록했다. 사용자가 claude.ai chat에서 SKILL.md 세 곳을 고쳤다. 절차 2단계, 보고 템플릿의 "확인할 내용" 자리 표시, 템플릿 채우기의 "확인할 내용" 항목이다. 동기화된 사본을 repo에 바이트 그대로 복사했다. "## 한국어 글쓰기 규칙" 절은 바뀌지 않아 복사본 검사를 통과한다.

고친 skill로 `ai-slop-guide`를 세 번 돌렸고, 질문 수는 거의 늘지 않았다. 원인을 가리려고 같은 글에서 군더더기 여덟 문장을 뺀 변형 글을 만들어 돌렸다. skill을 쓴 쪽은 질문을 하나도 묻지 않았고, 쓰지 않은 쪽은 셋에서 넷을 물었다.

## 비교 기준

skill 없이 돌린 실행이 공통으로 물은 빠진 정보 네 가지를 기준으로 셌다.

- (a) 승인을 받은 뒤에 사야 하는지
- (b) 20일이 지난 뒤에는 어떻게 하는지
- (c) "다음 달 급여"가 어느 달 기준인지
- (d) 구독 서비스를 지금 청구할 수 있는지

## 결과

| 입력 | 설정 | "확인할 내용"에서 물은 것 | grader 21개 |
|---|---|---|---|
| `ai-slop-guide` | 고치기 전 skill (0152) | (c), (c), (c) | 21, 21, 21 |
| `ai-slop-guide` | 고친 skill | (a)(c), (a), (a) | 21, 20, 20 |
| `ai-slop-guide` | skill 없음 (0152) | (a)(b)(c)(d), (a)(c)(d), (a)(b)(c) | 12, 12, 11 |
| 변형 글 | 고치기 전 skill | 없음, 없음, 없음 | 채점하지 않음 |
| 변형 글 | 고친 skill | 없음, 없음, 없음 | 채점하지 않음 |
| 변형 글 | skill 없음 | (a)(b)(c)(d), (a)(b)(c), (a)(b)(c) | 채점하지 않음 |

- 고친 skill은 질문 수가 1, 1, 1에서 2, 1, 1로 바뀌었을 뿐이다. 묻는 주제가 (c)에서 (a)로 옮겨 가, (c)를 보는 grader 19에서 두 번 떨어졌다.
- 군더더기 문장 빼기, 정보가 있는 문장 남기기, 보고 템플릿, 반영 전에 묻기는 세 번 모두 그대로 통과했다.
- 변형 글에서 고친 skill은 세 번 모두 "고칠 곳을 찾지 못했습니다." 한 줄만 냈다.

## 진단

- chat은 "글이 길거나 고칠 곳이 많을 때 질문이 줄어드는지" 확인해 달라고 했다. 그렇지 않았다. 고칠 곳이 없는 짧은 글에서 질문은 0개로 더 줄었다.
- 같은 글에서 skill이 없으면 묻는 질문을 skill이 있으면 묻지 않는다. 원인은 SKILL.md 안에 있다.
- 고치기 전 skill(commit `22bf2dd`의 SKILL.md)도 변형 글에서 세 번 모두 질문을 하나도 묻지 않았다. 원인은 이번 수정 전부터 있던 부분이다. 이번에 더한 문장은 질문을 막지도 늘리지도 못했다.
- 그 부분이 SKILL.md의 어느 문장인지는 가리지 않았다.
- 후속: 이 진단은 근거를 잃었다. 변형 글 실행은 작업 폴더 이름 `eval-clean-variant`를 볼 수 있었고, [[0154-korean-review-reader-walkthrough-step]]에서 오염 없는 조건으로 다시 돌린 skill은 빠진 정보를 물었다.
- 변형 글은 진단용이라 repo에 넣지 않았다.

## 남은 것

- grader 19는 (c) 하나만 본다. 빠진 정보를 묻는지 재려면 (a)~(d) 가운데 몇 개를 묻는지 보는 쪽이 맞다.
- 변형 글을 case로 두면, 고칠 곳이 없는 글에서 빠진 정보를 묻는지 따로 잴 수 있다.
