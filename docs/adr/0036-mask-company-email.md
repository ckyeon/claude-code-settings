# 0036 — Mask the defunct company email in public docs

The repo is public and two docs (ADR 0026, migration runbook §4) carried the defunct company account email verbatim. "회사 계정" carries the same meaning without the address, so the parentheticals are dropped. The address remains in these files' git history and in past commit authorship; a history rewrite was considered and rejected as not worth the cost for a dead account.
