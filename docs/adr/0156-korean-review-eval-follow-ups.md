# 0156 — 2026-11-26 ai-slop-guide의 grader 19가 구매 순서를 묻는지 보게 하고, 격리해 돌리는 방법을 적음

[[0155-korean-review-isolated-three-way-eval]]의 후속 두 가지다.

- grader 19가 보는 질문을 "다음 달 급여"의 기준에서 "팀장 승인 전에 산 책도 지원하는지"로 바꿨다. 오염 없는 조건에서 두 skill을 가른 것은 이 질문이었다. "다음 달 급여"의 기준은 독자가 몰라도 영수증을 올리는 일을 끝낼 수 있으므로, skill이 걸러도 되는 질문이다. `case.yaml`의 기대 결과도 같이 바꿨다.
- `claude-ai/README.md`의 "Test a skill"에 case를 격리해 돌리는 방법을 적었다. repo 밖 폴더에서 돌리고, 폴더 이름을 무작위로 짓고, `claude -p`에 claude.ai 동기화를 끄는 설정을 준다. 실행 스크립트는 repo에 넣지 않았다. 명령 하나와 폴더 준비만 있으면 되고, `bin/`에 도구를 더하면 시험까지 함께 관리해야 하기 때문이다.
