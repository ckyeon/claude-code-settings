# 0152 — 2026-11-26 ai-slop-guide case를 고치고 skill이 있을 때와 없을 때를 비교

[[0150-korean-review-ai-slop-eval-case]]의 case를 처음 돌렸더니, 입력과 grader에 결함이 드러나 고쳤다. 고친 case를 skill-creator 절차로 설정마다 세 번 돌렸다. skill을 쓰면 grader 21개를 세 번 모두 통과했고, skill 없이는 평균 55%를 통과했다.

## 고친 것

- **입력**: "이번 분기에 입사한 분"을 "새로 입사한 분"으로 바꿨다. 시간이 지나면 틀린 말이 되는 문제가, 독자를 밝힌 문장을 남기는지 보는 검사와 섞였다. 처음 돌린 두 실행이 모두 이 점을 짚었다.
- **grader를 나눴다**: 남길 문장 네 종류는 하나씩(09~12), 반영 여부를 묻는 것과 파일을 고치지 않는 것은 따로(20, 21), 첫 문장과 AI slop 절의 위치도 따로(16, 17) 본다.
- **grader를 바꿨다**: 16은 첫 문장의 N이 실제 줄 수와 같은지도 본다. 18은 문장 일부만 고치는 줄도 채점할 수 있게 바꿨다.
- **grader를 더했다**: 여덟 문장 밖의 문장을 빼자고 하지 않는지(14), "다음 달 급여"가 어느 달 기준인지 묻는지(19)를 본다.
- grader는 14개에서 21개가 됐다.

## 실행 방법

- 실행마다 subagent 하나를 썼다. skill을 쓰는 쪽은 repo의 SKILL.md를 읽게 했고, 쓰지 않는 쪽은 `korean-review`를 부르거나 읽지 말라고 했다. 두 쪽 모두 user scope의 한국어 rule은 로드된 상태다.
- 채점은 subagent grader 두 개가 skill-creator의 `agents/grader.md`대로 했다. 보고 여섯 개를 섞어 R1~R6으로만 넘겼으므로, grader는 어느 보고가 어느 설정인지 몰랐다.
- 결과 파일은 이 기기의 임시 폴더에 두었고 repo에는 넣지 않았다.

## 결과

| | skill 사용 | skill 없음 |
|---|---|---|
| 통과한 grader | 21, 21, 21 | 12, 12, 11 |
| 통과율 | 100% | 55% |
| 평균 시간 | 120.1초 | 124.2초 |
| 평균 token | 84,284 | 75,616 |

- skill 없이도 빼야 할 문장 여덟 개는 세 번 모두 빼자고 했다. 01~08 가운데 skill 없는 쪽이 떨어진 것은 04 하나이고, 문장을 못 찾아서가 아니라 부정 대구라는 이유를 대지 않아서다.
- 차이가 난 곳은 남길 문장을 남기는 것(09는 세 번 중 두 번, 10~12는 0번), 그 밖의 문장을 빼지 않는 것(14), 보고 템플릿(16~18), 반영 전에 묻는 것(20)이다. skill 없는 쪽은 이 항목들을 한 번도 통과하지 못했다.
- skill 없는 쪽은 세 번 모두 문서에 빠진 정보를 더 많이 물었다. 신청과 구매 중 무엇이 먼저인지, 20일이 지난 뒤에는 어떻게 하는지, 구독 서비스를 지금 청구할 수 있는지다. skill 쪽은 세 번 모두 "다음 달 급여"의 기준 하나만 물었다. [[0126-korean-writing-rule-and-review-skill]]에서 본 경향과 같다. SKILL.md의 "확인할 내용"은 앞뒤나 사실과 맞지 않는 곳과 글쓴이가 정할 곳만 적으라고 하고, 독자에게 필요한데 빠진 정보는 언급하지 않는다. 이것이 원인일 수 있지만 확인하지는 않았다.
- 고치기 전 case로 설정마다 한 번 돌린 결과는 skill 사용 14개 중 14개, skill 없음 14개 중 8개였다.

## 남은 것

- grader가 지적한 결함은 고치지 않았다. 이번 결과가 지금 grader로 잰 것이기 때문이다.
  - 14가 10~12와 겹쳐, 남길 문장을 지운 실수 하나가 두 번 감점된다.
  - 13은 문장을 지우지 않고 뜻만 바꿔 쓴 경우를 통과시킨다.
  - 18의 "which sentence"는 소제목을 되풀이하는 7행에 맞지 않는다.
  - 15는 번역투를 아예 보지 않는 리뷰도 통과한다.
- 빠진 정보를 묻는지 보는 grader는 없다. skill은 claude.ai chat에서 고치므로([[0151-rule-keeps-files-written-with-symbols]]), 이 동작을 바꿀지는 chat에서 정한다.
