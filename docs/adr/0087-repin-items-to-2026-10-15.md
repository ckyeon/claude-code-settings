## 바뀐 내용

copied 항목은 local 내용이 바뀌었다.

- **herdr** (v0.9.5, `2ecf19a9`): v0.9.4 동작에 맞춘 주의사항 네 가지가 추가됐다. Ctrl+Z로 중단해도 agent identity는 유지되지만 foreground에 있다는 뜻은 아니다. `idle`과 `done`이 입력 준비를 보장하지 않는다. `pane run` 성공은 대기열에 들어갔다는 뜻이고, macOS에서는 line-input 한도를 넘는 명령을 거부한다. CLI와 API의 close에는 TUI의 마지막 pane 확인이 없다.
- **agent-browser `core`** (v0.39.1, `1165952d`): `--engine`(chrome, lightpanda, obscura)과 `--use-system-ca` flag가 문서에 들어갔고, `--ca-cert`가 CLI 요청에도 적용된다고 설명이 넓어졌다. Obscura engine의 proxy bypass 제약도 추가됐다.

inspired-by 항목은 pin만 옮겼다. 다섯 건 모두 등록 command가 그대로다.

- **fetch** (`bbb701e7`): SSRF 방어가 추가돼 사설, loopback, cloud metadata 주소를 기본으로 거부한다. `--allow-private-ips`로 끈다. 버전 표기가 CalVer(2026.10.10)로 바뀌었다.
- **sequential-thinking** (`bbb701e7`): 첫 semver release 1.0.0이다. tool annotation을 바로잡았고, `__proto__` 같은 `branchId`가 호출을 깨뜨리던 버그를 고쳤다.
- **context7** (`ef472a49`): `@upstash/context7-mcp`가 4.2.0에서 4.4.1로 올랐고 `query-docs`에 선택 인자 `language`가 생겼다.
- **github** (`c59e8c19`): `repo://` resource URI 인코딩 수정과 `/ui` 의존성 bump다.
- **remotion** (`2d5b9c18`): plugin 4.0.535다. `<Series>` 대신 `<TransitionSeries>`를 쓰고, component와 `<Composition>` 등록을 별도 파일에 두도록 안내가 바뀌었다. skill 12개 구성은 그대로다.

pin만 뒤처진 17건은 내용 변경이 없다. `claude-plugins-official` 7건, next.js 5건, auto-editor 3건, `understand-anything`, `dogfood`다.
