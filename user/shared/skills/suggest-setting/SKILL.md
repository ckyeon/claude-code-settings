# 설정 건의

`~/.claude` 아래 설정은 설정 repo로 symlink되어 있고, 설정 repo는 변경마다 ADR과 commit을 남긴다. 다른 프로젝트 세션은 고칠 점을 건의로 남기고, 설정 repo의 세션이 그것을 처리한다. 건의는 이 skill 디렉터리의 `suggest-setting`이 inbox에 파일 하나로 쓴다. 이 파일은 설정 repo의 `bin/suggest-setting`을 가리키는 symlink이고, 옵션은 `--help`가 정본이다.

## 1. 건의할 일인지 가린다

건의 대상은 `~/.claude` 아래의 사용자 설정이다. 이 세션에서 다음 중 하나가 일어났으면 건의할 일이다.

- skill, rule, hook이 틀리게 동작했거나 서로 어긋났다.
- 사용자가 모든 프로젝트에 적용할 지시를 했는데 그 지시가 설정에 없다.
- 사용자가 시키지 않았는데 `~/.claude` 아래 파일을 고쳐야겠다고 판단했다.

다음 경우는 건의하지 않고 바로 고친다.

- 사용자가 `~/.claude` 아래를 고치라고 했다.
- 지금 프로젝트의 `.claude/`와 `CLAUDE.md`를 고친다. 이 파일들은 이 프로젝트의 것이다.
- 지금 세션이 설정 repo 안이다. 그 repo의 절차를 따른다.

## 2. 한 번 묻는다

건의를 한 줄로 요약하고 "설정 repo에 건의로 남길까요?"라고 묻는다.

- 승인하면 3단계로 간다.
- 거절하면 이 세션에서 같은 건의를 다시 묻지 않는다.

사용자가 건의를 직접 요청했으면 이 단계를 건너뛴다.

## 3. 쓴다

이 프로젝트 디렉터리에서 실행한다. 현재 디렉터리가 건의를 보낸 프로젝트로 기록된다.

```bash
~/.claude/skills/suggest-setting/suggest-setting --title "<한 줄 제목>" --target "<~/.claude 기준 경로>" <<'EOF'
## 관찰
<무엇이 일어났고 무엇을 기대했는지>

## 제안
<무엇을 어떻게 바꿀지>

## 근거
<사용자 발언 인용, 오류 문구, 관련 파일 경로>
EOF
```

- `--target`은 `skills/tdd/SKILL.md`처럼 쓰고, 관련 설정마다 하나씩 붙인다. 대상을 모르면 뺀다.
- 본문은 이 세션의 대화를 모르는 사람이 이 파일만 읽고 확인할 수 있을 만큼 쓴다.
- secret은 값 대신 이름만 적는다.

script가 출력한 경로를 사용자에게 알리면 끝난다.
