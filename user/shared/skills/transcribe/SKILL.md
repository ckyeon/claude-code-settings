# Transcribe — 로컬 파일 Gemini 전사

```bash
python3 ~/.claude/skills/transcribe/scripts/transcribe.py <파일> [--out <경로>] [--anchors [초]] [--plain]
```

옵션과 동작은 `--help`가 정본이다. 스크립트가 말하지 않는 것만 여기 둔다.

## 실행 전 확인

- **키**: `GEMINI_TRANSCRIBE_API_KEY`만 읽는다(범용 `GEMINI_API_KEY`는 읽지 않는다 — 다른 과금 프로젝트와 섞이지 않게). 없으면 즉시 오류로 끝나므로 먼저 `echo ${GEMINI_TRANSCRIBE_API_KEY:+set}`로 확인한다.
- **과금**: 입력 토큰만 과금, 분당 약 0.003 USD(46분 실측 0.14 USD, 2026-09-02). 무료 티어는 분당 토큰 한도 때문에 25분 청크마다 대기가 생긴다 — 스크립트가 429 지시대로 기다리므로 그대로 두면 된다.
- **의존**: `curl`, `ffmpeg`/`ffprobe`(25분 초과 분할·영상 오디오 추출).

## 앵커를 켤지 정한다

기본은 앵커 없음이다. `--anchors`는 word timestamp를 켜는 옵션이고, 공식 문서는 이것이 정확도를 소폭 낮출 수 있다고 경고한다. 그러므로 **원문 위치 인용이 필요한 경우에만** 켠다 — 예: 위키처럼 전사문을 나중에 대조·인용할 때. 강의 노트·회의록처럼 본문만 필요하면 켜지 않는다. 사용자가 말하지 않았으면 이 기준으로 고르고 결과 보고에 어느 쪽을 골랐는지 적는다.

## 결과 다루기

- 산출물은 확률적 원문이다(ASR). frontmatter `transcript:`가 모델·모드를 남기므로 지우지 않는다.
- 고유명사(모델·제품·인명)는 오청취가 흔하다. 요약·정리에 쓰기 전에 의심되는 표기는 사용자에게 확인한다.
- 화자 표지는 없다. 발언자 구분은 문맥으로 한다.
